# IXC + Sicoob Reconciler 🏦

> Conciliação bancária automatizada entre IXC Soft e Sicoob · Automated bank reconciliation between IXC Soft and Sicoob

---

## 🇧🇷 Português

Sistema que automatiza a conciliação de **boletos e pagamentos** entre o sistema de telecom **IXC Soft** e a instituição financeira **Sicoob**. Elimina a necessidade de conciliação manual e reduz erros operacionais.

### ✨ Funcionalidades
- Conciliação automática de boletos
- Conciliação de pagamentos bancários
- Detecção de divergências
- Geração de relatórios de conciliação
- Logs completos para auditoria

### 🛠 Stack
- **Linguagem:** TypeScript
- **Framework:** Node.js
- **Banco:** PostgreSQL
- **Deploy:** Docker

### 🚀 Como usar
```bash
git clone https://github.com/KaduSR/ixc-sicoob-reconciler.git
cd ixc-sicoob-reconciler
npm install
cp .env.example .env
# Editar .env com credenciais do IXC e Sicoob
npm start
```

### 📊 Métricas
| Métrica | Valor |
|---------|-------|
| Automação | 100% |
| Integrações | 2 (IXC + Sicoob) |

## 🇺🇸 English

System that automates the reconciliation of **invoices and payments** between the telecom system **IXC Soft** and the financial institution **Sicoob**. Eliminates the need for manual reconciliation and reduces operational errors.

### ✨ Features
- Automated invoice reconciliation
- Bank payment reconciliation
- Discrepancy detection
- Reconciliation report generation
- Complete audit logs

### 🛠 Stack
- **Language:** TypeScript
- **Framework:** Node.js
- **Database:** PostgreSQL
- **Deploy:** Docker

### 🚀 Usage
```bash
git clone https://github.com/KaduSR/ixc-sicoob-reconciler.git
cd ixc-sicoob-reconciler
npm install
cp .env.example .env
# Edit .env with IXC and Sicoob credentials
npm start
```
